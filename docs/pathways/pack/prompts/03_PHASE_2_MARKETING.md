# PHASE 2 PROMPT - Marketing Website and Design System
Build the public Pathways experience with the approved component system. Use the supplied two homepage mockups as visual direction only, never a flattened screenshot or authority for their embedded claims.

Design: polished, calm and aspirational; navy, restrained teal/green, warm neutrals; generous spacing; readable headings and real responsive cards. Implement semantic HTML and reusable tokens. Do not hard-code text positioning that breaks on narrow screens. No carousel is required.

Homepage hero: School Should Fit Your Child's Life. Not Limit It.
Supporting meaning: explore flexible educational pathways around the student's learning, interests and future. Primary CTA: Find My Student's Pathway. Secondary: See How It Works.

Include goals for athletics, flexible schedules, homeschool support, academic opportunity, a different environment and unsure. Explicitly welcome K-12 while maintaining the 5-12 emphasis. Clicking a goal preselects an editable profile interest only.

Implement /, /how-it-works, approved /pathways/[slug] audience pages, /for-partners, and legal-page shells restricted from live use until approved. All visible links/actions must work or honestly indicate availability. No invented staff, partners, outcomes, testimonials, accreditation, free service promise or operating school. A sample Discovery Report is clearly labeled fictional.

Use properly licensed/provided images; keep a media source register. Do not assume mockup photography is separately available. Missing imagery should not block a clean design. Add public metadata and sitemap; private routes remain excluded.

Acceptance: responsive screenshots at 375, 768 and 1440 CSS pixels; 320-pixel reflow and zoom checks; keyboard navigation, visible focus, contrast and reduced-motion behavior; all CTA links verified; no overflow or text clipped inside boxes; no synthetic social proof. Target WCAG 2.2 AA without claiming conformance before testing.
